### 🌟 Featured Projects

#### 1. 🎓 [LearnIQ Backend](https://github.com/SanemIzci/LearnIQ-backend)
> **Production-grade, event-driven, multi-tenant SaaS backend for test-prep academies.**
- **Architecture**: Microservices built with **Spring Cloud Gateway**, Auth Service, Exam Service, Notification Service, and AI Service.
- **Multi-Tenancy**: Schema-per-tenant data isolation using dynamic Hibernate routing and Flyway migrations.
- **AI Integration**: Event-driven Kafka pipeline orchestrating LLMs (Gemma / OpenRouter) and uploading personalized reports to AWS S3.
- `Java 21` `Spring Boot 3.3` `Apache Kafka` `PostgreSQL` `AWS S3` `Hibernate` `Docker`

#### 2. ⚡ [Notification Control Center (NCC)](https://github.com/SanemIzci/notification-control-center)
> **High-throughput, event-driven notification microservice platform (Email, SMS, Push).**
- **Performance & Reliability**: Sub-20ms Kafka ingestion (`202 Accepted`), Idempotency key deduplication, and Exponential Backoff with BullMQ.
- **Fault-Tolerance**: Dead Letter Queue (DLQ) for failed message containment and error recovery.
- **Real-Time Monitoring**: Live SSE (Server-Sent Events) dashboard built with Next.js & Tailwind CSS v4.
- `NestJS` `TypeScript` `Apache Kafka` `Redis / BullMQ` `Next.js` `PostgreSQL` `Docker`

- **RAG Chatbot**: Contextual QA chatbot powered by FAISS vector store, Sentence Transformers, and EU COSING ingredient database.
